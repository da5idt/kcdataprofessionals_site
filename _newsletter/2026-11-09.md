    url: "https://airflow.apache.org/blog/airflow-3.4.0/"
    source: "Apache Airflow blog"
    published: "Nov 6, 2026"
    summary: "Airflow 3.4.0 adds Task Loops, which repeat a group of tasks a number of times decided at runtime, plus experimental support for Dags (workflows) written in YAML, TypeScript, Java or Go. Psycopg3 becomes the default Postgres driver and Python 3.10 support is dropped. On Nov 9 the project disclosed 18 CVEs (published security vulnerabilities) fixed by this release, including one that let anyone who could write to the Celery message broker run code on every Celery worker, and one that left connection and variable secrets in readable audit logs."

    source: "Databricks blog"
    published: "Nov 5, 2026"
