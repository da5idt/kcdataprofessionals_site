    url: "https://www.openwall.com/lists/oss-security/2026/10/28/9"
    source: "oss-security list"
    published: "Oct 28, 2026"
    summary: "The Kafka project published a batch of security advisories on Oct 28. The most serious affects brokers that use OAuth token login without a JWKS endpoint (the URL Kafka uses to check token signatures): an attacker could forge a token and log in as any user. Versions 4.1.0 to 4.3.0 are affected, it is fixed in 4.2.2, 4.3.1 and 4.4.0, and setting sasl.oauthbearer.jwks.endpoint.url protects you without upgrading."
    why: "If you run Kafka with OAuth, check that setting today, and plan an upgrade for the rest of the batch."
